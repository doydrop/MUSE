Game tebak angka 1–20 dan kalkulator baris perintah. Dibangun sebagai latihan Fondasi Tahap 2, dirapikan jadi repo GitHub pertama yang riwayat commit-nya bisa dibaca orang lain.

Lihat di GitHub Tentang pembuatnya 

$ python3 tebak_angka.py
Tebak angka 1-20 (ketik 'q' untuk keluar).
Tebakanmu: 10
Terlalu kecil.

$ python3 kalkulator.py
> 5 + 3
= 8.0

Isinya

Game tebak angka

Komputer menyimpan satu angka rahasia 1–20. Setiap tebakan dibalas petunjuk "terlalu kecil" atau "terlalu besar". Ketik q untuk keluar.

Kalkulator CLI

Ketik 5 + 3 lalu Enter. Operator + - * /. Bagi nol dan operator asing ditangani tanpa crash.

Repo yang rapi

4 commit, satu perubahan satu commit: chore, dua feat, satu docs. README menjelaskan cara jalanin dan struktur project.

Cara jalanin

  1. Butuh Python 3 saja, tanpa library tambahan.
  2. Clone repo: git clone https://github.com/doydrop/MUSE.git
  3. Jalankan: python3 tebak_angka.py atau python3 kalkulator.py

Coba sendiri

Repo ini publik dan gratis. Kalau mau belajar dari file kosong seperti saya, mulai dari Fondasi: satu bahasa, satu repo, satu commit kecil setiap kali.
